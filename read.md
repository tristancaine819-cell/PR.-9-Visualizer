📊 Pandas Analyzer & Data Visualization

A comprehensive menu-driven Python application for loading, exploring, cleaning, analyzing, and visualizing CSV datasets using Pandas, NumPy, Matplotlib, and Seaborn.

This project was developed as part of the Red & White Skill Education Project and demonstrates practical applications of Data Analysis, Data Cleaning, Data Visualization, and Object-Oriented Programming (OOP) in Python.

🚀 Features
📂 Dataset Management
Load CSV files from any location
Create a sample dataset for testing
Save modified datasets to new CSV files
Export filtered datasets
🔍 Data Exploration
View first and last 5 rows
Display dataset dimensions
View column names
View data types
Check dataset information
Find duplicate rows
Detect missing values
